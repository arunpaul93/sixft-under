# Six Feet Under Excavations

Static website for a family owned excavation business servicing Northern NSW and South East Queensland.

## Open locally

Open `dist/index.html` in a browser. The website's images, video, styles and JavaScript are contained in `dist/`.

## Hosting

Deploy `dist/` as the public directory. No dependency installation or build step is required. The existing `.openai/hosting.json` identifies the current Sites deployment.

## Verify

From this directory, run `node verify.cjs` and `node --check dist/script.js`.

## Assets

The business badge and field footage were supplied by the business. The navigation uses `dist/assets/brand-badge-transparent.png`.
